# Getting Started with WOS

## What is WOS?

WOS (Way Of Success) is a small educational programming language.
It's designed to teach beginners low-level concepts
(pointers, manual memory allocation) without C's scary syntax.

WOS compiles to C, then to a binary.

## Requirements

Before you start, make sure you have:

- **clang** — to compile WOS and the generated C code
- **node.js** — for the language server (optional)
- **vim** — for the best editing experience (optional)

Install on Termux:

```bash
pkg install clang nodejs vim
